# Andrei Pinter Photography

A photography portfolio arranged by place: one gallery per US state, and per country everywhere else.

Live: https://photography.andreipinter.com/

## What's here

- `index.html`, `styles.css`, `app.js`: the whole site. Plain HTML, CSS and JavaScript, no framework or build step.
  - **Places** opens on a full-screen photograph with every place listed beside it. Point at (or scroll to) a place and its cover photograph fades in; each place takes its accent colour from that photograph.
  - Each **place** page has a cover, the place's coordinates, a filter by city, and a justified grid that opens with the strongest frames.
  - **All photographs** lists everything newest first, by year.
  - The viewer works with arrow keys, swipes and Escape, and every photograph has its own link.
- `data.json` and `img/`: generated by `tools/build.py` (below). Three sizes per photograph: `sm` 800px, `md` 1600px and `lg` (the export itself, up to 3072px). `app.js` gives the browser each file's real width so it never stretches a smaller file than the space needs. None of them carry EXIF, XMP or GPS data; the build stops if any does.
- `fonts/`: Big Shoulders Display and Newsreader, served from this site (SIL Open Font License).

## Updating the photographs

The photographs are captioned on Andrei's Mac with the private `photo-tools` scripts (place, date, camera and lens from the originals, with corrections in `captions.csv`). Their export folder is the input here:

```
python3 tools/build.py --src ~/Documents/Claude/Projects/Website/andreipinter-site
git add -A && git commit -m "Update photographs" && git push
```

`tools/places.json` sets each place's cover photograph, main city and coordinates. Pushing to `main` deploys through GitHub Actions.

## Custom domain

To serve it at your own domain, add a `CNAME` file containing the domain (for example `photos.andreipinter.com`), push, and at the DNS provider (Squarespace Domains) add a CNAME record pointing that host to `adpinter-create.github.io`. Then turn on **Enforce HTTPS** under Settings, Pages.

Moving the main `andreipinter.com` here instead means pointing the apex at GitHub's Pages IP addresses and retiring the Squarespace site, so do that only once this site has everything you want from the old one.
